Processing pipeline

Original → Grayscale → Threshold → Edges → Contours → Desmos equation box (right). No in-app graph — paste the box into Desmos manually.

Desmos equation

Single box — paste the whole thing into Desmos at desmos.com/calculator (it splits into lines). Format: y=... {a<=x<=b}, circles, (x(t),y(t)) {0<=t<=1}, polygon(...).
–

How to paste into Desmos

  1. Click Copy all.
  2. Open desmos.com/calculator.
  3. Click the first empty expression line and paste (Ctrl+V) — Desmos creates one line per row.
  4. For Color mode: select each pasted line's color dot and match the hex shown at the end of the line's layer (see .txt download for color map).
  5. Zoom out / press ⌂ — art lives in −10…10.
